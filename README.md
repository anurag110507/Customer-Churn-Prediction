# Retainova — AI-Powered Customer Churn Prediction

Retainova is a machine learning project that analyzes customer data, predicts the likelihood of customer churn, and provides risk-based retention recommendations through an interactive Streamlit dashboard.

## Problem Statement

Customer churn occurs when customers stop using a company's products or services. Identifying customers who may leave helps businesses investigate customer concerns and plan retention strategies.

## Project Objectives

- Analyze customer churn patterns using Exploratory Data Analysis (EDA).
- Clean and preprocess customer data.
- Train and compare machine learning classification models.
- Estimate churn probabilities for individual customers.
- Categorize customers into high-, medium-, and low-risk groups.
- Generate rule-based retention recommendations.
- Visualize results in an interactive dashboard.

## Features

- **Churn Analytics:** Visualize churn distribution, contract patterns, and monthly charges.
- **Customer Prediction:** Estimate churn probability from customer details.
- **Customer Risk Analysis:** Rank customers by predicted churn probability.
- **Risk Filtering:** Filter customers by risk category and contract type.
- **Retention Recommendations:** Display suggested retention actions for high-risk customers.
- **CSV Export:** Download risk analysis and retention recommendation reports.

## Technology Stack

- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn, Streamlit
- **Machine Learning:** Scikit-learn, XGBoost
- **Model Storage:** Joblib
- **Development Environment:** VS Code, Jupyter Notebook

## Machine Learning Models

The project compares three classification algorithms:

1. Logistic Regression
2. Random Forest
3. XGBoost

### Model Evaluation

The models are evaluated using accuracy, precision, recall, F1-score, and ROC-AUC.

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 80.55% | 65.72% | 55.88% | 60.40% | 84.21% |
| Random Forest | 75.94% | 53.36% | 74.33% | 62.12% | 83.62% |
| XGBoost | 79.91% | 65.22% | 52.14% | 57.95% | 84.26% |

These are the evaluation results recorded during development. Model selection depends on the business objective: Random Forest has the highest recall and F1-score in this comparison, while XGBoost has the highest ROC-AUC.

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd "Customer Churn"
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
python -m streamlit run app.py
```

## Important Notes

- The trained model and dataset must be available at the paths expected by the application.
- Risk categories use initial probability thresholds and may require further validation.
- Retention recommendations are rule-based suggestions, not predictions generated by a separate recommendation model.
- Historical dataset scoring is not a substitute for evaluating the model on unseen customers.
